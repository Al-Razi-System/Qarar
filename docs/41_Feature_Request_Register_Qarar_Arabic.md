# Qarar
## سجل طلبات الميزات

**الحالة:** فهرس تنفيذي مرجعي  
**الغرض:** الوصول إلى طلب الميزة المرتبط بكل مهمة تنفيذية داخل خطة `MVP`.

---

## 1. قاعدة التوثيق

كل مهمة في وثائق الـ `Initial Issues` تحمل الآن حقلاً صريحاً باسم `Feature Request` بالصيغة `FR-xx-yy`.

لا يكرر هذا السجل وصفاً موازياً للمهمة. طلب الميزة التفصيلي هو بطاقة الـ Issue نفسها، ويشمل إلزامياً:

- `Goal`
- `Scope`
- `Out of Scope`
- `Acceptance Criteria`

تضيف وثائق طلبات الميزات المنفصلة قيمة العمل، والقواعد الحاكمة، والرحلة الأساسية، والتبعيات الدقيقة عندما تكون الميزة ضمن السبرنت الجاري.
