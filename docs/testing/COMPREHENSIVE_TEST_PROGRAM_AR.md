# برنامج الاختبار الشامل لمنصة قرار

## الهدف

اكتشاف العيوب غير المعروفة، وليس فقط منع رجوع العيوب التي أبلغ عنها المستخدم. يعتمد
البرنامج على المخاطر والرحلات المترابطة والاختبار متعدد الأدوار والبيانات القديمة.

## طبقات الاختبار

1. **الثوابت والعقود:** الحالات، الصلاحيات، المعرّفات، حدود المؤسسة وعقود API/RPC.
2. **اختبارات المكونات:** حالات التحميل والنجاح والرفض والتعارض وفشل الشبكة في موضع الإجراء.
3. **اختبارات قاعدة البيانات:** القيود، التزامن، المعاملات، RLS، السجلات القديمة والترحيلات.
4. **اختبارات التكامل:** المتصفح والخادم وقاعدة البيانات والتخزين والإشعارات معاً.
5. **رحلات E2E متعددة الحسابات:** ينفذ كل مستخدم الجزء الخاص بدوره، ولا يعاد استخدام جلسة
   مدير النظام لتمثيل الرئيس أو المقرر أو العضو.
6. **اختبار استكشافي منظم:** إدخالات ناقصة، نقر مكرر، تحديث الصفحة، رجوع المتصفح، انقطاع
   الشبكة، شاشتان تعملان في الوقت نفسه، شاشة ضيقة، وبيانات عربية طويلة.
7. **اختبارات غير وظيفية:** الأداء، الوصول، RTL، الأمان، النسخ والاستعادة والمراقبة.

## أبعاد إلزامية لكل رحلة

- البيانات: جديدة، قديمة قبل آخر ترحيل، ناقصة، مكررة، عربية طويلة، ملف غير صالح.
- الحالة: كل انتقال مسموح، كل انتقال ممنوع، تحديث متزامن، إعادة إرسال الطلب نفسه.
- الهوية: صاحب السجل، مخول في السياق، مخول عالمياً دون سياق، غير مخول، مؤسسة أخرى.
- الواجهة: سطح مكتب وشاشة ضيقة، تحميل بطيء، خطأ 4xx، خطأ 5xx، استجابة غير JSON.
- الاستمرارية: تحديث الصفحة وتسجيل الخروج والدخول بعد كل مرحلة حساسة.
- الأثر: قاعدة البيانات، سجل التدقيق، الإشعار، الشاشة التالية والتقرير أو المحضر.

## بوابات الإصدار

- لا اختبارات P0 فاشلة أو متجاوزة.
- لا `console.error` أو وعد مرفوض في الرحلات الناجحة والمتوقعة الفشل.
- لا مواصفات E2E موجودة خارج قائمة التشغيل دون استثناء موثق.
- نجاح ترقية قاعدة تحتوي بيانات سابقة، لا قاعدة فارغة فقط.
- تقرير نتائج يوضح النجاح والفشل والمحجوب وسبب الحجب، ولا يدمجها في نسبة واحدة مضللة.

## ترتيب التنفيذ

1. إصلاح خط أساس الاختبارات حتى يصبح مستقراً وقابلاً للتكرار.
2. المستخدمون وعضويات المجالس.
3. ملكية جدول الأعمال وحالات الاجتماعات الدورية.
4. الرحلة الكاملة للاجتماع متعددة الحسابات.
5. الموضوع والمسارات السابقة والمخصصة والاستثناءات.
6. اللوائح والإصدارات والمعرفات التلقائية.
7. تنفيذ القرارات والتقارير والمراقبة والأداء.
