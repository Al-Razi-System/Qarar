# قالب تحليل أثر التغيير

يُملأ هذا القالب قبل أي تغيير وظيفي. يمكن وضعه في وصف المهمة أو طلب الدمج.

## تعريف التغيير

- المشكلة أو الحاجة:
- القاعدة التجارية المراد حمايتها:
- السلوك الحالي المثبت:
- السلوك المتوقع:
- ما هو خارج النطاق:

## خريطة الرحلة

- المرحلة السابقة:
- المرحلة المعدلة:
- المرحلة التالية:
- الحالة قبل العملية:
- شروط السماح:
- الحالة بعد النجاح:
- الحالة بعد الفشل أو التراجع:

## خريطة التأثير

- الواجهات والأزرار:
- API وRPC وEdge Functions:
- الجداول والعروض والدوال والمشغلات:
- المهام المجدولة والإشعارات:
- التقارير والمحاضر وسجل التدقيق:
- الأدوار المسموح لها والممنوعة:
- المستهلكون الآخرون للعقد:
- البيانات القديمة والعمليات الجارية:

## خطة الاختبار

- اختبار يعيد إنتاج العطل:
- نجاح المسار الأساسي:
- رفض الإدخال غير الصحيح:
- رفض الدور غير المخول:
- التعارض والنقر المكرر:
- فشل الشبكة أو الخادم:
- المرحلة السابقة واللاحقة:
- سطح المكتب والشاشة الضيقة:
- استعلام تحقق البيانات بعد العملية:

## خطة الإصدار

- الترحيل أو إصلاح البيانات:
- طريقة التحقق المرحلي:
- مؤشرات المراقبة:
- طريقة الرجوع أو الإصلاح الأمامي:
