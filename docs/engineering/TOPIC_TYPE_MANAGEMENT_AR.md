# إدارة تصنيفات الموضوعات — خريطة الأثر

## نطاق هذه الدفعة

عرض قائمة فعلية قابلة للبحث والتصفية والترقيم، وتفاصيل التصنيف المحفوظ (السند والمرفقات والنطاق والدورية)، وتحرير مسودة المنشئ باستخدام عقد الحفظ الذري الموجود ورقم القفل. يُتاح التحرير للتصنيفات الجديدة ذات إعدادات التأليف فقط، منعًا لإسقاط إعدادات قديمة لا يغطيها هذا المحرر. تظل الإنشاءات وعقود الحفظ القائمة صالحة. لا نغيّر دورة الاعتماد في هذه الدفعة ولا نتجاوز فصل المراجع عن المنشئ.

## الرحلة والثوابت

إنشاء مسودة ← إغلاق المحرر ← ظهورها في القائمة ← عرض تفاصيلها. القراءة بلا أثر جانبي؛ لا تُنشّط مسودة ولا تنشئ موضوعًا أو بند جدول أعمال. كل النتائج محصورة في مؤسسة الجلسة وبصلاحية governance.model.read؛ لا تمنح صلاحية القراءة تعديلًا أو تنشيطًا.

## المستهلكون والعقود

واجهة topic-types-workspace، مكوّن قائمة مستقل، GET governance-model?view=types، والعقد api_v2.list_governance_topic_types_v2 الجديد. التفاصيل تستخدم get_governance_bundle_v2 الموجود. كشف المتصفح أن الغلاف لا يملك EXECUTE للمستخدم المصادق؛ أضيفت الصلاحية لهذا الغلاف فقط في ترحيل تصحيحي مستقل، مع بقاء assert_permission وعزل المؤسسة ومنع anon وservice_role. اختُبر هذا التغيير صراحةً بدل إبقاء اختبار الإصدار التجريبي القديم الذي يشترط حجب تفاصيل التصنيف. مصادر القراءة: topic_types_v2 وtopic_type_versions_v2 وtopic_classifications_v2 وgovernance_bundles_v2. لا جداول أو مشغلات أو وظائف دورية جديدة ولا تعديل للصفوف السابقة.

## الحالة والفشل والتراجع

حالة البيانات قبل وبعد القراءة واحدة. تحميل/قائمة فارغة/لا نتائج/فشل مع إعادة المحاولة تظهر في مكانها. طلب التفاصيل القديم يُلغى عند تغيير الاختيار. فشل التفويض يعيد رسالة عربية آمنة ورقم تتبع. التراجع عن الواجهة لا يحتاج ترحيل بيانات عكسيًا؛ الترحيل الجديد إضافي فقط.

## الاختبارات والقيود المعلنة

اختبارات API للتوجيه والتحقق، وواجهة للقائمة والتفاصيل والفشل والبحث وإعادة تحميل المسودة والتحقق من إرسال هوية السجل ورقم القفل، وقاعدة بيانات للتفويض وعزل المؤسسات والترقيم. اختبار الإنشاء السابق يبقى قائمًا. العدد لا يُخمّن: لا يوجد حاليًا ربط بين topics وتصنيفات V2، لذلك يعرض «غير متاح بعد» لا صفرًا. المتبقي: تعديل التصنيفات المنشورة بنسخة آمنة؛ دورة التنشيط والتعطيل مع حماية السجلات الجارية؛ ربط إنشاء الموضوع بتصنيف V2 ثم حساب التقديمات. لا يُسمح باعتبار هذه الدفعة إتمامًا لتلك العمليات.
