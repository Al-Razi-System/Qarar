# خريطة أثر تأسيس المجلس وخطة اجتماعاته V2

## تعريف التغيير والثابت التجاري

- المشكلة: عقد وواجهة إنشاء المجلس يطلبان رمزاً تقنياً، ويفصلان إنشاء المجلس عن خطة اجتماعاته، ويعرضان إعدادات إدارية كثيرة دفعة واحدة.
- الثابت: المستخدم يدخل الاسم والنوع والنطاق فقط؛ UUID والمرجع والرمز التوافقي يولدها الخادم. خطة الاجتماعات اختيارية، وإن اختيرت تحفظ مع المجلس في معاملة واحدة.
- قبل: إنشاء مجلس غير نشط بعقد V1 ثم إنشاء سلسلة اجتماعات منفصلة تولد كل الاجتماعات مقدماً.
- بعد: إنشاء مسودة مجلس بعقد V2 اختياري الخطة. تحفظ الخطة فقط ولا تنشئ اجتماعاً أو تغير حالة المجلس تلقائياً.
- خارج النطاق: توليد الاستحقاقات زمنياً، تعيين القيادة والأعضاء، التفعيل، وترحيل المجالس القديمة.

## خريطة الرحلة والحالات

- السابقة: تعريف نوع مجلس ونطاق تنظيمي صالحين.
- المعدلة: إدخال البيانات الأساسية، فتح الإعدادات المتقدمة عند الحاجة، ثم حفظ المجلس والخطة.
- التالية: إضافة القيادة والأعضاء، فحص الجاهزية، ثم التفعيل.
- قبل العملية: لا سجل، أو إعادة آمنة لنفس `client_request_id`.
- بعد النجاح: مجلس `inactive` وخطة `draft` اختيارية.
- بعد الفشل: لا مجلس ولا خطة؛ تبقى مدخلات الواجهة ويظهر الخطأ داخل نافذة الإنشاء.

## خريطة التأثير

- الواجهة: نافذة إنشاء المجلس فقط؛ التعديل القديم يبقى مؤقتاً حتى بناء عقد تحديث V2.
- العقود: إضافة `admin_create_council_v2` دون تغيير توقيع V1.
- البيانات: إضافة مرجع تلقائي للمجالس وجدول خطط اجتماعات مستقل؛ لا تعديل للسلاسل أو الاجتماعات القديمة.
- الصلاحية: `governance.units.manage` لإنشاء المجلس، و`meetings.create` في نطاق المجلس عند طلب الخطة.
- التدقيق: حدث للمجلس وحدث للخطة داخل المعاملة.
- المستهلكون: البحث والتفاصيل والعضويات والاجتماعات تستمر بعقودها الحالية.

## الإعدادات

- الأساسية: الاسم، نوع المجلس، النطاق، وخيار خطة الاجتماعات.
- الخطة الأساسية: الدورية، أول موعد، والوقت.
- المتقدمة المطوية: الاسم الإنجليزي، الوصف، الحد الأدنى للأعضاء، الجمع بين القيادة، نهاية الخطة، والمهلة قبل اعتبار موعد غير منعقد فائتاً.
- القيمة الافتراضية لمهلة الفوات: 7 أيام، ولا تغير حالة اجتماع فعلي في هذه الدفعة.

## الاختبار والإصدار

- اختبار واجهة يثبت غياب الرمز اليدوي، بقاء المتقدم مطوياً، والقيم الافتراضية.
- اختبار قاعدة يثبت التوليد التلقائي، الذرية، إعادة الطلب، الصلاحية، ورفض المراجع العابرة للمؤسسة.
- اختبار المرحلة السابقة: الخيارات لا تعرض نوعاً أو نطاقاً غير صالح.
- اختبار المرحلة التالية: المجلس الناتج قابل لإضافة العضويات وفحص الجاهزية.
- لا نشر إنتاجي قبل تطبيق الترحيل واختبار الرحلة على بيئة معزولة.
