# إزالة نموذج نوع الوحدة المستقل

## النطاق والأثر قبل التنفيذ
- الرحلة: تجهيز الهيكل التنظيمي ثم إضافة وحدة وربطها بالمجلس.
- المطلوب: إزالة نموذج إنشاء النوع المكرر من صفحة الوحدات؛ إبقاء إنشاء النوع داخل قائمة النوع في نافذة إضافة الوحدة.
- المستهلكون: OrganizationalUnitsWorkspace وOrganizationalUnitDialog واختبارات الواجهة؛ لا تغيير في API/RPC أو الجداول أو الوظائف أو الصلاحيات أو العقود.
- الحالات: الصفحة تعرض القائمة وزر إضافة الوحدة؛ نافذة الوحدة تحتفظ باختيار النوع وإنشائه والصلاحية الخاصة به ورسائل الانتظار والنجاح والفشل في موضع الإجراء.
- البيانات القديمة والترحيل: لا تغييرات ولا استعادة للوحدات التي حذفها المستخدم؛ لا ترحيل مطلوب.
- الفشل والتراجع: حماية الإنشاء القائمة باقية؛ يمكن استعادة مكون العرض دون تغيير البيانات.
- الاختبارات: اختبار فاشل أولًا لغياب النموذج المستقل؛ اختبارات الإنشاء داخل القائمة وحفظ المدخلات والأخطاء ورفض الصلاحيات، مع التعديل والحذف والترقيم كرحلات مجاورة؛ typecheck وlint وفحص حوكمة التطوير.

## نتيجة التحقق
- فشل اختبار غياب النموذج قبل الإزالة، ثم نجحت اختبارات الواجهة الثلاثة عشر بعد الإزالة.
- نجح typecheck وeslint للملفين وفحص حوكمة التطوير وترميز المستندات وgit diff --check.
- مجلد المشروع مربوط مباشرة بحاوية التطوير لتحديث الواجهة؛ لم يُنفذ نشر إنتاجي أو تغيير بيانات.
- لم يُعد اختبار متصفح شامل لهذه الإزالة المحدودة؛ التحقق الحالي على مستوى المكونات، ولا يُعد ضمانًا لجميع عمليات النظام.
