# خيار إضافة النوع داخل القائمة وتوضيح ارتباط المجلس

- الرحلة: قائمة نوع الوحدة ← خيار إضافة نوع جديد ← محرر موضعي ← اختيار النوع الحقيقي ← إنشاء الوحدة ← اختيارها للمجلس.
- الثوابت: خيار الإضافة إجراء واجهة فقط، وليس قيمة نوع ولا يُرسل للخادم. لا يفقد النوع المختار السابق أو اسم الوحدة أو الجهة الأم عند إلغاء الإضافة. صلاحية إضافة النوع مستقلة وتمنع إظهار الإجراء لغير المخول.
- الفحص المثبت: scope_units يعيد سجلات governance_units غير المجلسية، وscopeUnitId يرسل UUID الوحدة إلى p_scope_unit_id ثم يخزنه المجلس في scope_unit_id. الربط بالوحدة موجود بالفعل؛ «النطاق التنظيمي» تسمية مضللة توحي بكيان ثانٍ. لا حاجة لحقل ربط إضافي.
- التأثير: OrganizationalUnitDialog، InlineUnitTypeEditor، CouncilFormDialog واختباراتهما وسكربت المتصفح. لا تعديل API أو مخطط أو مشغلات أو سجلات قديمة أو أدوار. نفس admin_create_organizational_unit_type_v2 ونفس عقد إنشاء المجلس.
- الحالات: يفتح محرر النوع من خيار داخل select؛ النجاح يضيف النوع ويختاره، الفشل يبقى داخل المحرر، الإلغاء يبقي النوع السابق. النقر المكرر/الحفظ والإغلاق محميان كما في الحزمة السابقة. لا تغيير دورة حياة.
- توضيح المجلس: إعادة تسمية الحقل «الوحدة التنظيمية» وشرح أنها تحدد نطاق المجلس. اختيار المؤسسة كاملة يبقى null طبقًا للعقد الحالي. المجلس الأب يبقى علاقة مستقلة، ولا نستنتج مجلسًا أبًا تلقائيًا من أب الوحدة.
- اختبار سابق للتنفيذ: غياب زر الإضافة الخارجي ووجود الخيار داخل القائمة؛ إلغاء يحفظ الاختيار؛ رفض عرض الخيار دون الصلاحية؛ الحقل المسمى الجديد يمرر UUID الوحدة ذاته. إعادة اختبار الإضافة والفشل ومنع Enter، إنشاء المجلس وحفظ scope، ومتصفح مكتبي و390px.
- الإصدار: hot reload في التطوير فقط؛ الرجوع بالواجهة دون ترحيل. typecheck/lint/focused tests/development-governance إلزامية.

## نتائج التحقق

- قبل التنفيذ فشلت اختبارات خيار الإضافة داخل القائمة وإلغاء الإضافة والتسمية الجديدة للحقل.
- بعد التنفيذ نجحت 20 حالة مكون/API، و16 حالة قاعدة بيانات لإنشاء المجلس؛ معرف الوحدة المختارة يصل كما هو ولا يطلب نطاق مستقل، والمجلس الأب لا يتغير.
- Typecheck وESLint للملفات المتأثرة وdiff --check ناجحة.
- رحلة فعلية على devqarar بحساب معزول وجلسة AAL2 نجحت على الكمبيوتر و390px: إضافة النوع من داخل القائمة وحفظ المدخلات، إنشاء الوحدة ثم المجلس المرتبط بها، الفشل المتوقع 409 داخل النافذة، واستخدام Enter في محرر النوع على الهاتف. لا runtime errors أو HTTP 5xx؛ حساب الاختبار عُطل بعد الفحص.
- لا ترحيل أو تغيير بيانات مؤسسة المستخدم أو إنتاج. الاختبار لا يغطي تغيير وحدة مجلس قائم أو نطاق الصلاحيات الموروثة؛ هذه العمليات خارج هذه الحزمة.
