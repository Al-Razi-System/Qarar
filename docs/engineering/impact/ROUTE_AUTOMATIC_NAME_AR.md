# اقتراح اسم المسار من المراحل

قبل التنفيذ: الاسم حقل يدوي بمثال لنوع موضوع؛ المطلوب اسم يصف ترتيب المجالس.
الرحلة: اختيار المجالس وترتيبها ← اقتراح اسم قابل للتخصيص ← حفظ المسار وربطه بنوع موضوع.
الثابت: الاسم وصف عرض وليس هوية أو سياسة؛ لا يتغير اسم محفوظ تلقائيًا عند فتحه.

المستهلكون: RouteDesigner ونموذجه واختباراته، اسم القائمة والتصنيف من name_ar.
عقد admin_save_route_layout_v2 يبقى كما هو: name_ar نص نهائي؛ لا أعمدة أو مشغلات
أو وظائف مجدولة أو أدوار جديدة، ولا تعديل للمعرفات أو دورات الحياة.
صلاحية الإدارة الحالية وحدود المؤسسة تبقى في الخادم دون تغيير.

المسار الجديد يبدأ بتسمية تلقائية من أسماء الجهات المختارة بالترتيب؛ تغيير الترتيب
والحذف والاختيار يحدّث الاقتراح. الكتابة اليدوية توقف الاستبدال حتى يختار المستخدم
«استخدام الاسم التلقائي». السجلات المحفوظة تفتح بوضع يدوي لحماية أسمائها، حتى إن
شابهت اقتراحًا. لا نخزن وضع التسمية؛ الاسم وحده محفوظ وفق العقد السابق.
الاسم المقترح محدود بسقف العقد 300 حرف، ولا يضم حالة المجلس أو جهات غير مختارة.
الفشل يحفظ الاسم ومفتاح إعادة المحاولة؛ التعارض والتحقق والتنشيط دون تغيير.

اختبار ارتداد قبل التنفيذ: التوليد، إعادة الترتيب والحذف، تخصيص يدوي لا يضيع، العودة
للتلقائي، اسم قديم محفوظ لا يستبدل، payload الحفظ يحمل الاقتراح، وفشل الحفظ والتكرار.
التحقق: اختبارات الواجهة المركزة، typecheck وlint وحوكمة التطوير؛ معاينة سطح مكتب وجوال.
لا نشر إنتاجي أو ترحيل بيانات؛ الرجوع بإرجاع سلوك محرر الاسم دون مساس بالمحفوظ.

التحقق المنفذ: اختبار الاقتراح فشل أولًا لغياب التوليد ثم نجح بعد التنفيذ، مع حفظ
الاسم اليدوي والسابق. typecheck وlint للملفات المتأثرة وحوكمة التطوير نجحت.
اختبار المتصفح المعزول على نطاق التطوير نجح: توليد وترتيب وتخصيص والعودة للتلقائي،
ثم حفظ وفشل وإعادة محاولة وتنشيط واختيار المسار في نوع موضوع وحفظ سياسته.
فُحصت لقطة جوال 390px دون تجاوز أفقي؛ احتُفظ بسجلات الاختبار وعُطلت هويته المؤقتة.
