# خريطة أثر استكمال إعداد جدول أعمال الاجتماع

## الرحلة والثابت التجاري

- الرحلة: رئيس المجلس يفتح مسودة اجتماع من تفاصيلها، ثم يختار «استكمال الإعداد
  وجدول الأعمال» لإدراج موضوع وصل عبر المسار أو إنشاء موضوع مباشر.
- الثابت: لا تتغير حالة الاجتماع ولا يُدرج أي موضوع بمجرد فتح مساحة الإدارة؛ كل
  إضافة تظل عبر عقود جدول الأعمال الحالية وصلاحياتها وقفلها حسب حالة الاجتماع.

## السبب الجذري

- زر الاستكمال يرسل `manage=<meeting-id>` إلى صفحة الاجتماعات.
- مساحة الاجتماعات تؤجل فتح الاجتماع بمؤقت، لكنها تسجل أن المعرف استُهلك قبل
  تنفيذ المؤقت. في وضع React Strict Mode يُلغى المؤقت في دورة التحقق الأولى، ثم
  تمنع العلامة الدورة الثانية من فتح الاجتماع.
- تهيئة العرض المكتبي تحول الصفحة إلى التقويم، لذلك يرى المستخدم قائمة/تقويم
  الاجتماعات بدل جدول أعمال الاجتماع المطلوب.

## المستهلكون والعقود والواجهات

- الواجهات: صفحة `/admin/meetings/[meetingId]`، وصفحة `/admin/meetings`، ومكون
  `MeetingsWorkspace`، ولوحة `MeetingAgendaPanel` ونوافذ المقترحات والموضوع المباشر.
- العقود المقروءة كما هي: `get_meeting_detail`، `get_meeting_readiness`،
  `search_eligible_agenda_topics`، و`list_meeting_topic_attachments`.
- عقود التعديل كما هي: `add_agenda_item`، `remove_agenda_item`،
  `reorder_agenda_items`، و`create_direct_agenda_topic_v2`.
- لا تغيير في الجداول أو الترحيلات أو حالات المجال أو الصلاحيات.

## الحالة والانتقال والفشل

- قبل الإجراء: الاجتماع `draft` أو `scheduled`، وجدول أعماله قابل للتحرير وفق
  `can_manage_agenda`، والموضوع المباشر وفق `can_add_direct_topic`.
- الإجراء: فتح مساحة مركزة للاجتماع المحدد وإظهار أدوات الجدول التي يسمح بها العقد.
- بعد الإجراء: تبقى حالة الاجتماع كما هي؛ لا تتغير إلا بيانات الواجهة المقروءة.
- الفشل: يبقى خطأ قراءة التفاصيل في موضع مساحة الإدارة مع إمكانية العودة إلى كل
  الاجتماعات؛ لا تعرض أزرار إضافة قبل نجاح القراءة.

## البيانات القديمة والرجوع

- لا إصلاح بيانات ولا ترحيل. جميع الاجتماعات الحالية تستفيد من المسار المركز.
- الرجوع برمجياً يعيد صفحة الاجتماعات العامة دون تغيير أي سجل.

## الاختبارات الواقية

- اختبار يفشل أولاً إذا لم يفتح `initialMeetingId` الاجتماع المحدد في الوضع
  المركز، أو ظهرت واجهة التقويم، أو غابت أزرار المقترحات والموضوع المباشر.
- إبقاء اختبارات فتح رحلة الاجتماع من بطاقات القائمة، وإضافة الموضوع المباشر،
  ولوحة جدول الأعمال.
- فحص TypeScript وESLint وحوكمة التطوير، ثم قبول يدوي على `devqarar` للاجتماع
  `MTG-2026-000007` بصلاحية رئيس المجلس.
