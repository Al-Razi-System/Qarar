# استكمال اعتماديات إنشاء المجلس

- الرحلة: تجهيز الوحدات التنظيمية ← إنشاء مجلس بنطاق تنظيمي ومجلس أب مستقل ← خطة اجتماعات اختيارية بنوع نشط.
- العطل: لا سطح UI لإنشاء النطاق؛ المجلس الأب مخفي؛ توقف الخطة بلا رابط. عقد إنشاء الوحدة v1 يطلب p_code يدويًا.
- الثوابت: نوع الوحدة ليس مجلسًا، والجهة الأم من المؤسسة نفسها وغير مؤرشفة وليست مجلسًا. UUID ثابت ومرجع ORU مولد بالخادم. لا إنشاء مجالس أو اجتماعات تلقائيًا لهذه العملية.
- العقود: إضافة api_v2.admin_list_organizational_units_v2 وadmin_create_organizational_unit_v2 عبر /api/admin/councils؛ إبقاء عقود v1 دون تغيير. المستهلكون: صفحة /admin/organizational-units، نموذج المجلس، الشريط الجانبي. بحث المستودع أثبت غياب مستهلك لعقدي V2 الجديدين.
- البيانات: governance_units وgovernance_unit_types، reference_counters_v2، api_contract_registry، append_audit_log، مشغلات الوحدة الحالية. لا إصلاح أو حذف للسجلات السابقة ولا تغيير لجداول عضويات أو جدولة.
- الحالات: وحدة تنظيمية جديدة active للاستخدام كنطاق (لا تمر بجاهزية قيادة المجلس)؛ مجلس جديد يبقى inactive حسب عقده الحالي. الفشل يُرجع المعاملة كاملة. إعادة الطلب بمفتاح UUID تعيد النتيجة نفسها تحت قفل؛ مرجع ORU لا يطلب من العميل. لا تغيير دورة حياة موجودة.
- الصلاحيات: governance.units.read للقراءة وgovernance.units.manage للإنشاء في سياق المؤسسة الحالية؛ المستخدم غير المخول والمؤسسة الأخرى مرفوضان. الواجهة تخفي الإنشاء دون manage؛ قاعدة البيانات هي المرجع النهائي.
- واجهة الوحدة: اسم/نوع/جهة أم اختيارية، بحث وترقيم؛ لا حذف أو أرشفة في هذه الحزمة. pending/error داخل النموذج، حفظ المدخلات عند الفشل، نجاح واضح بعد الإغلاق. روابط الاعتماديات تفتح تبويبًا آخر لحفظ مدخلات المجلس مع زر تحديث القوائم.
- اختبار قبل التعديل: المجلس الأب ظاهر دون فتح المتقدم، روابط الاعتماديات؛ عقد الإنشاء V2؛ pgTAP للمرجع والتكرار والصلاحيات والمؤسسة الأخرى ورفض نوع المجلس وظهور الوحدة كنطاق؛ اختبارات المكون للخطأ والنقر المكرر والبحث والترقيم. اختبار السابق (أنواع الوحدات) واللاحق (نطاق المجلس/إنشاؤه وخطته).
- الإصدار: ترحيل إضافي على قاعدة التطوير المعزولة فقط، Hot Reload؛ ممنوع تعديل الترحيلات المطبقة أو الإنتاج. الرجوع UI إلى السابق مع إبقاء العقد الإضافي، بلا حذف بيانات. lint/typecheck/focused tests/development-governance إلزامية؛ التحقق المتصفحي الحقيقي قد يحتاج MFA المستخدم، ولا نبدل عامله.
- اعتماد إضافي مثبت: قاعدة التطوير تحتوي نوع وحدة واحدًا «إدارة»؛ لذلك توفير إضافة نوع وحدة باسم فقط من نفس الواجهة ضروري لإنشاء كلية/قسم بلا رمز يدوي. العقد admin_create_organizational_unit_type_v2 يفرض governance.unit_types.manage مستقلة عن صلاحية إنشاء الوحدة، يولد رمز OUT، ويعيد النوع الموجود عند تكرار الاسم تحت قفل. لا تحويل لأنواع المجالس ولا seed ولا تغيير لتعريفات سابقة. اختبار نوع/إعادة طلب/رفض غير مخول قبل التنفيذ.
- فحص مجاور كشف خلل بحث: الواجهة تعد بالبحث بالمرجع ORU، لكن العقد يبحث في code ذي الشرطات السفلية فقط. أضيف اختبار فاشل للمرجع المعروض أولًا؛ التصحيح يوسع مرشح القراءة نفسه ليشمل reference_number، دون تغيير الحالات أو الصلاحيات أو المعرفات. ترحيل تصحيحي إضافي لأن الترحيل الأول طُبق في التطوير؛ لا تعديل له.

## نتائج التحقق في التطوير

- 14 اختبار واجهة/API ناجحة من إعداد Vitest الخاص بـ apps/dashboard؛ تشغيل أول من جذر المستودع لم يستخدم إعداد DOM/aliases وأعيد تشغيله من المجلد الصحيح.
- 37 اختبار قاعدة بيانات ناجحة: إنشاء المجلس V2 (16)، الوحدات (17)، أنواع الوحدات (4). تشمل رفض مؤسسة أخرى والصلاحيات والتكرار والبحث والترقيم والذرية وحالة المجلس الجديدة وخطة الاجتماعات الاختيارية.
- Typecheck وESLint للملفات المتأثرة ناجحان. سجل الترحيلات يطابق 208 ملفات مصدر.
- رحلة متصفح حقيقية على devqarar بحساب جديد مستقل داخل مؤسسة اختبار: جلسة AAL2 بعامل MFA خاص بالاختبار، إضافة نوع وكلية، رفض التكرار برسالة داخل النافذة مع حفظ المدخلات، إنشاء مجلس بنطاق الكلية، وإظهار المجلس الأب دون المتقدم ورابط أنواع الاجتماعات. فحص الهاتف 390px نجح بلا تمرير أفقي والأزرار قابلة للوصول؛ لا أخطاء runtime أو HTTP 5xx في الرحلة.
- إجراء متكرر: `node scripts/test-organizational-units-dev-browser.mjs`. لا يستعمل حساب المدير الحالي أو عامل MFA له أو حد محاولاته؛ يسجل بيانات الاختبار في مؤسسة مستقلة، ويعطل حساب الاختبار في finally مع إبقاء سجل التدقيق.
- التحقق محدود بهذه الرحلة، وليس شهادة بخلو النظام كله من الأخطاء. إنشاء نوع اجتماع وخطته اختبرا عقديًا في اختبار المجلس؛ دورة الاجتماع والمحضر خارج نطاق هذه الحزمة. لم يتم نشر أو ترحيل أي شيء إلى الإنتاج.
