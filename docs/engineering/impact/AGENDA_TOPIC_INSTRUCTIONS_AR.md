# توحيد المقترحات وتعليمات الموضوع المدرج

قبل التنفيذ: تعرض شاشة الاجتماع المقترحات في بطاقة، ثم تكرر الإضافة في ترويسة التفاصيل وحالة جدول الأعمال الفارغ. يبقى موضع المقترحات وحده؛ قائمة «عرض جميع المقترحات» امتداد له وليست مسار إضافة مستقلًا. يسمى زر إعداد الموعد «تحديد وقت الاجتماع».

الرحلة: موضوع مكتمل ولقطة تصنيفه ← مقترح لدى المجلس الحالي ← مراجعة تعليمات المناقشة والإدراج ← جلسة تعرض التعليمات الخاصة. رئيس المجلس بعضوية فعالة في المجلس نفسه يستطيع تخصيص التعليمات عند الإدراج أو بعده أثناء المسودة/الجدولة فقط. المقرر والعضو والمسؤول العام دون رئاسة لا يملكون هذا التخصيص. الإدراج العادي وصلاحياته القائمة محفوظان.

التخزين على بند جدول الأعمال، لا التصنيف أو لقطة الموضوع: قيمة null تعني التعليمات الموروثة، والنص الفارغ تخصيص بلا تعليمات. السجلات السابقة ترث النص كما كانت. الحفظ الجديد يدرج بواسطة add_agenda_item ثم يحفظ التعليمات في المعاملة نفسها، والتعديل يقارن updated_at؛ قفل الاجتماع يمنع السباق مع بدء الجلسة. فشل أي شرط يتراجع عن الإدراج والنص معاً. التدقيق يحفظ الفاعل والنص السابق والجديد. لا مهمة دورية أو تغيير مسار أو تصويت أو محضر.

العقود المتأثرة: save_agenda_topic_instructions جديد في meetings، get_meeting_detail وsearch_eligible_agenda_topics يعيدان النص وقدرة الرئيس. API الاجتماعات يسمح بالعقد الجديد؛ تجميد v1 وتعداد اختبارات 13/20/28/42 ووثائق العقود يحدثان. المستهلكون: شاشة الاجتماع، المقترحات، جدول الأعمال، غرفة الاجتماع وTopicCard. جدول agenda_items يضيف عموداً فقط، بلا جدول أو ترميم بيانات.

الاختبارات أولاً: إلغاء الإضافة المكررة، فتح محرر بالتعليمات الموروثة، حفظ وإدراج وفشل يبقي النص، منع الأدوار الأخرى والمؤسسة الأخرى، تعارض نسخة، رفض بعد قفل التحضير، ثبات التصنيف واللقطة وعرض النص المخصص للجلسة. تشغيل الاختبارات المركزة والعقود والأنواع وlint والبناء والحوكمة، ثم التطوير بعرضي 1440/390. لا إنتاج؛ الترحيل أمامي فقط والواجهة السابقة تبقى متوافقة مع العمود الجديد.

الاختبار قبل التغيير أعاد إنتاج زر الإضافة المكرر. اختبار SQL97 يفشل قبل العقد الجديد، وينجح بعده 11/11 بما في ذلك الإدراج الذري والتكرار والتعارض والأدوار. نجحت ملفات القاعدة الـ98 كاملة على القاعدة المعزولة؛ ثم وُسع اختبار الموضوع المصنف 82 إلى 36 تأكيداً ونجح، ويثبت أن التخصيص لا يغير لقطة التقديم أو إعداد التصنيف. نجحت وثائق العقود الـ229 وlint مع التحذيرات الستة المعروفة. خيار scrollContent في Dialog (معطل افتراضيًا) يبقي ترويسة نافذة التعليمات وزر الحفظ داخل الشاشة، ويمرر جسم المحرر وحده. نجحت فحوص النسخة النهائية: 24 اختبار واجهة مركزًا، والفحص الصارم للملفات المعدلة، والبناء وفحص الأنواع والحوكمة. طُبق الترحيل على التطوير بعد نسخة احتياطية، مع ثبات بصمة العضويات وتطابق سجل الترحيلات الـ295. نجحت تجربة المتصفح وHTTP الفعلية للرئيس والمقرر والعضو بعرضي 1440 و390، بما فيها ظهور زر الحفظ داخل شاشة الهاتف، والإدراج مرة واحدة، وقراءة التعليمات المخصصة، ورفض تعديلها للمقرر والعضو. محاولة سابقة توقفت عند مهلة خدمة المصادقة قبل فتح الواجهة؛ نجحت الإعادة بعد انتهاء البناء. حسابات التجربة محظورة بعد الاختبار؛ لم يُمس الإنتاج.
