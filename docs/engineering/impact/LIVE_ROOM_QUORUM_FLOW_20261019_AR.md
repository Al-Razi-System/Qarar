# غرفة الاجتماع: النص المختلط وتسلسل الإجراءات والنصاب

## خريطة الأثر قبل التنفيذ — 19 أكتوبر 2026

- الرحلة: تثبيت الحضور ← قرار الرئيس عند نقص النصاب ← مناقشة ← تصويت ← قرار ← محضر. لا يُغيّر الاستثناء الحضور أو النسبة أو نتيجة النصاب إلى مكتمل.
- قرار المالك: الرئيس يختار التأجيل أو متابعة الاجتماع بنصاب غير مكتمل؛ الاجتماع وقراراته يحتفظان بهذا الوصف. ليست صلاحية مسؤول النظام أو المقرر وحدها تفويضًا بهذا القرار.
- المستهلكون: `get_meeting_session_detail`، `apply_quorum_failure`، `update_agenda_discussion`، `open_voting_round`، `complete_meeting_session`، حارس حالة الاجتماع، القرارات والمحضر وواجهات الحضور والغرفة. يُستكمل جرد شروطها قبل أي تعديل خلفي؛ لا يُعطّل حارس دون بديل معاملاتي.
- البيانات: الاجتماعات الحالية ناقصة النصاب تحتاج اختيارًا صريحًا، ولا تُمنح استثناءً بأثر رجعي. الجداول والقرارات القديمة تبقى صالحة. أي إصلاح خلفي بترحيل أمامي فقط، مع قفل الاجتماع وتحقق التزامن وتدقيق الفاعل والسبب.
- العرض: المحتوى الفعلي المحفوظ يحتوي HTML وMarkdown مهروبًا داخل حاويات `div`. إصلاح القراءة والمعاينة مشترك، دون تعديل لقطة التصنيف المحفوظة ودون السماح بـ script أو iframe أو روابط خطرة. تُحمى الأكواد والهروب العادي من التغيير.
- الطاولة: استبدال المدار النسبي الذي يتقاطع مع سطح الطاولة بمناطق مقاعد منفصلة هندسيًا، مع تمرير المشهد كله بدل قص نصفه. لا تغيير لحضور أو أصوات أو عضوية.
- الإجراءات: الخطوة الأساسية أولًا، البدائل داخل قائمة صريحة؛ إنهاء الجلسة يظهر بعد إنهاء البنود فقط. أسباب المنع لا تختفي.
- اختبارات البداية: مثال فعلي مختلط للتعليمات، سلامة HTML، عدم ظهور إجراءات الإنهاء المبكر، وبقاء البدائل متاحة. ثم اختبارات النصاب للأدوار المسموحة والمرفوضة والتزامن وما قبل وبعد التصويت والمحضر قبل إطلاق الاستثناء.
- الفشل: تبقى البيانات السابقة، تظهر رسالة عربية في موضع الإجراء، لا تكرار إرسال ولا تجاوز صامت للنصاب. لا نشر لتغيير خلفي قبل نجاح اختبارات قاعدة معزولة.

## نتيجة التنفيذ والتحقق

- ترحيل أمامي `20261019010000_explicit_quorum_continuation`، بلا عقود جديدة: يمدد `apply_quorum_failure` بخيار `continue` ويضيف قراءة الصلاحية والسبب واللقطة، ويصل المناقشة والتصويت والإتمام والمحضر بالقرار ذاته. وسم القرار مشتق من ارتباطه بالاجتماع وقراره غير القابل للمحو، وليس نصًا يُلحق بصياغة القرار.
- DB109: فشل قبل الإصلاح؛ 25 تأكيدًا ناجحًا بعده حتى مصادقة المحضر وإغلاق الاجتماع. يغطي رفض المقرر والمدير والمستخدم الأجنبي والنسخة القديمة، وعدم محو القرار أو إزالة تنبيه المحضر. بقيت متطلبات التصويت والملخص النهائي مطبقة.
- نجحت **109 ملفات قاعدة بيانات** من مصدر الترحيلات في PostgreSQL 17 مع إضافات Supabase، داخل حاوية منفصلة بلا شبكة. استُخدمت بدائل `Auth/Storage` في تجهيز هذه القاعدة، وليست حزمة Supabase HTTP كاملة. حُدث تجهيز DB102 وDB103 لإتمام الحضور الحقيقي قبل النقاش؛ وسُجلت بصمات الترحيلات المطبقة في سجل القاعدة المؤقتة لتشغيل DB15.
- اختبار جلستين حقيقيتين: طلب تأجيل متزامن ينتظر استمرار الرئيس ثم يُرفض بـ`40001`، ولا يمحو القرار الأول ولا يصنع نصابًا مكتملًا. سكربت التكرار `supabase/tests/concurrency/quorum_continuation_lock.mjs` لا يقبل إلا حاوية اختبار مفصولة عن الشبكة.
- نجح الفحص الشامل **591 اختبار واجهة / 120 ملفًا**، ونجح الفحص المركز الأخير **28/28** ويشمل حماية أمثلة الأكواد والفشل الموضعي على آخر مصدر. التشغيل الأول الشامل كشف حالة كود Markdown عولجت قبل إعادة الفحص الشامل؛ لا تُقدّم نتيجته الأولى على أنها ناجحة.
- نجحت الأنواع والبناء الأخير، وlint دون أخطاء (التحذيرات الستة السابقة)، وبوابة الحوكمة وترميز الوثائق وفحص **229 عقدًا**.
- Storybook/Chromium: 10 حالات للرئيس والعضو، 1440 و1100 و390، فاتح/داكن؛ مع تحقق آلي أن مساحات المقاعد لا تتقاطع مع الطاولة، والتوسيع دون حركة الترويسة. تحقق إضافي بعرض 1440 وارتفاع 720 ومساحة غرفة قصيرة يبقي إجراء الرئيس مرئيًا؛ يجوز تمرير منطقة المقاعد عندما لا يسعها الارتفاع، ولا تتراكب مع الطاولة. هذه لقطات وتجارب مكونات، وليست دخولًا بحسابات حقيقية.
- جرى DB109 على **Supabase التطوير الحقيقي** أولًا ضمن معاملة تتضمن الترحيل ثم تُلغى كلها: 25/25. بعدها أُخذت نسخة احتياطية وطُبق الترحيل وسجل بصمته؛ عدد الترحيلات صار **307**، دون أي انحراف أو تغيير بصمات المستخدمين والعضويات والمجالس. النسخة: `backups/dev-before-quorum-flow-1792434250516.dump`.
- أثبتت قراءة الجلسة بصلاحية رئيس الاجتماع الحالي (مع سياق جلسته القائمة) أن `can_decide_quorum=true`، والنصاب `not_met`، والاجتماع `in_progress`، ولا اختيار متابعة محفوظ. **لم تُسجّل متابعة نيابة عنه ولم يُرجع الاجتماع للتحضير**؛ إكمال الاختبار يتم باختياره من النافذة. لا تغيير إنتاجي ولا إعادة كلمات مرور.
