# استعادة عرض بيانات المجلس والأعضاء

## السبب والثابت
قاعدة التطوير تحفظ عضويات مجلس الجامعة (12 سجل عضوية نشطاً)، لكن الشاشة تستدعي admin_get_council_detail_v2 قبل تطبيق ترحيله. Promise.all يرفض مجموعة القراءة ويعرض fallback بصفر أعضاء وقيم غير محددة. لا يوجد حذف للعضويات. الثابت: فشل القراءة ليس فراغ بيانات، ولا يعرض بيانات مجلس سابق عند تغيير الاختيار.

## الأثر والحدود
المرحلة السابقة اختيار المجلس من الشجرة؛ المعدلة قراءة التفاصيل/العضويات/الجاهزية؛ التالية عرضها ثم إدارة الأعضاء. API المجالس يتيح توافق قراءة محدوداً: عند PGRST202 للعقد الجديد فقط، يستدعي admin_get_council_detail القديم بالجلسة والمعلمات نفسها. لا fallback لرفض الصلاحية أو فشل الخادم أو أي mutation، ولا تغيير لعقود قاعدة البيانات أو العضويات أو أدوار أو jobs. تفاصيل الخطة غير المتاحة لا تعني عدم وجود خطة؛ يعاد علم صريح يوقف تعديل البيانات الجديد حتى إتاحة العقد، ولا يوقف إدارة العضويات القديمة.

## حالات الواجهة والاختبار
تحميل ← بيانات المجلس الصحيح أو خطأ موضعي مع إعادة المحاولة. لا أرقام أعضاء ولا قيم overview مزعومة عند الفشل، ولا بيانات اختيار قديم بعد اكتمال طلب متأخر. اختبار API يفشل أولاً بسبب غياب fallback، ويغطي رفض الصلاحية وأخطاء الخادم وغياب mutation. اختبار workspace يغطي الفشل وإعادة المحاولة والعدد الصحيح وتغيير المجلس أثناء تحميل متأخر. المكونات الجديدة Button/InlineMessage تستخدم tokens المشتركة. لا ترحيل أو إصلاح بيانات؛ التحقق بالمتصفح والقياسات 1440/390 بعد الاختبارات، دون نشر إنتاجي.

## النتائج
8 اختبارات API/Workspace ناجحة بعد فشل الحالات الثلاث التي أعادت العطل أولاً؛ ومع اختبار نافذة المجلس 18 اختباراً ناجحاً. فحص الأنواع ناجح وlint للملفات المعدلة ناجح. الفحص الشامل لـlint كشف قاعدة effect جديدة أثناء الإصلاح؛ صُححت دون تعطيل القاعدة. بوابة الحوكمة وترميز 170 وثيقة ناجحان.

scripts/test-council-detail-dev-browser.mjs نجح على devqarar بحساب AAL2 ومجلس ومؤسسة اختبار منفصلة: استدعاء API الحقيقي عاد 200 بالتوافق، عرض العضو، 1440/390 دون تمرير أفقي، فشل قراءة مقصود ثم إعادة محاولة ناجحة بلا أخطاء JavaScript. حسابات الاختبار تحظر في finally؛ لا تغيير للمجالس أو العضويات الفعلية. استعلام بعد الإصلاح أكد بقاء 12 سجل عضوية نشطاً لمجلس الجامعة. صور التحقق في /tmp/qarar-council-members-desktop.png و/tmp/qarar-council-members-mobile.png. تفاصيل خطة المجلس الجديدة ما زالت تنتظر إكمال بوابات الدفعة السابقة؛ لا يعرض غياب عقدها كغياب بيانات المجلس.
