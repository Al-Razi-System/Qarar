# استيراد حسابات تطوير وعضويات مجالس من الإنتاج

طلب المستخدم: إنشاء كلمات مؤقتة جديدة لحسابات الإنتاج وربطها بالمجالس في DEV.
المصدر qarar-supabase-db للقراءة فقط، مؤسسة qarar-demo؛ لا مؤسسات E2E.
الوجهة qarar-dev-supabase-db وAuth على 127.0.0.1:55421 حصرًا.
لا نسخ hashes أو tokens أو جلسات أو MFA أو علم مدير النظام أو صلاحيات عامة.
يُنقل الملف الشخصي وتُنشأ هوية جديدة عبر Auth admin ثم
service_finalize_temporary_user؛ active مع must_change_password=true
وحجب المؤسسة حتى تغيير الكلمة. لا دعوات ولا رسائل بريد.
الحساب المطابق بالبريد في DEV يبقى بكلمته وصلاحياته دون تغيير.

المجالس: مطابقة اسم كامل بعد تطبيع ألف وهمزات ومسافات فقط، دون fuzzy matching.
تُنقل عضويات council_member/council_chair/council_rapporteur النشطة غير المنتهية
إلى مجلس موجود غير مؤرشف ونوع فعال. الغائب/الملتبس يُسجل ولا يُخمن.
تظل بيانات القيادة عضويات بالعقود القائمة؛ لا تغيير حالة المجالس أو متطلباتها.
لا نقل أدوار إدارية أو تنفيذية أو عضويات تاريخية منتهية.
manage_user_role_v2 يفرض التزامن والحدود والتعارض ويسجل التدقيق؛ دفعة العضويات
في transaction مع advisory lock، بحيث أي فشل يتراجع بالدفعة كاملة.
Auth والخدمة ليسا transaction واحدة: يسجل ملف خاص كل هوية منشأة قبل الإكمال،
والإعادة تستكمل دون إعادة إنشاء أو تغيير كلمات لحسابات موجودة.
لا حذف تلقائي عند فشل الربط؛ التقرير يحدد ما يحتاج استكمالًا.

التسليم: ملف كلمات مؤقتة خاص 0600 خارج git؛ لا كلمات في السجلات أو المحادثة.
خطة التحقق: dry-run قبل أي كتابة، اختبارات مطابقة وتكرار وحدود قبل التنفيذ،
جرد عدد الهويات والعضويات وبعدها، تحقق must_change_password/no-admin، محاولة
دخول واحدة وإثبات حجب السياق قبل تغيير الكلمة، إعادة تشغيل بلا ازدواجية،
ثبات عدد المجالس وحالاتها والحساب الموجود. بوابة التطوير.
الرجوع: تعطيل الحسابات المضافة إذا طُلب، دون محو التدقيق أو سجلات الإنتاج.

## نتيجة التنفيذ

أُنشئت 50 هوية تطوير جديدة؛ بقي حساب المدير السابق بكلمته وصلاحياته.
أصبح العدد 51. كل حساب جديد active مع إلزام تغيير الكلمة، دون صلاحية مدير نظام.
كلمات مختلفة مولدة عشوائيًا في ملف 0600 خارج المستودع، ولا أسرار إنتاج منسوخة.
اعتمد المستخدم صراحة مطابقة المختبرات الطبية بالمختبرات، التغذية وصحة المجتمع
بصحة المجتمع والتغذية، وإدارة الأعمال الدولية باللغة العربية بإدارة الأعمال الدولية.
لم تُنشأ مجالس جديدة ولم يتغير وضع المجالس الـ36 غير النشطة.

تراجعت أول دفعة عضويات كاملة عند تعارض قيادة الأمناء مع مدير التطوير الحالي.
الإصلاح في أداة الاستيراد يكشف القيادة الموجودة ويتركها دون تغيير؛ لا إضعاف
للقيود ولا حذف عضويات. أضيفت 158 عضوية، وأصبح الإجمالي 161 مع الثلاث السابقة.
بقي تعيين رئيس ومقرر الأمناء من الإنتاج معلقًا لقرار المستخدم، وكذلك مجلسان
غير موجودين (التأديبي والطب والجراحة العامة). مجلس test مستبعد.

نجحت أربعة اختبارات مطابقة وحدود، والتحقق من كلمات مؤقتة إلزامية لجميع الخمسين،
ودخول Auth بكلمة جديدة مع بقاء سياق التطبيق محجوبًا حتى الاستبدال.
إعادة التشغيل لم تنشئ حسابًا أو عضوية إضافية. بوابة التطوير وdiff check ناجحتان.
لا ترحيل مخطط أو نشر إنتاجي؛ كل الكتابات على DEV بعقود إنشاء/عضوية مدققة.

## توحيد كلمات التطوير بطلب المستخدم — قبل التنفيذ

وافق المستخدم على كلمة موحدة للخمسين هوية الموجودة في ملف الاستيراد الخاص،
مع إبقاء الاستبدال إلزاميًا. عملية تشغيلية على DEV فقط وليست سياسة المنتج أو
كلمة للإنتاج. لا حساب المدير ولا أعضاء اختبارات أخرى ضمن النطاق.
التحقق القبلي: العدد 50، كل ID وبريد مطابق لملف الاستيراد، مؤسسة qarar-demo،
نشط وغير مدير، لا حجز تغيير كلمة قائم. لا تغيير للأدوار أو نطاقات التقديم.
يتغير Auth عبر admin API المحلي؛ بعدها تحدث بصمة الكلمة المؤقتة لتطابق Auth
وتلغى الجلسات بالعقد المدقق service_revoke_auth_sessions في المؤسسة نفسها.
لا نحفظ كلمة أو hash في التدقيق. تبقى must_change_password=true والحالة active؛
النجاح يثبت مطابقة البصمة وإلزام الاستبدال للخمسين. الفشل يوقف التنفيذ ويعرض
عدد المنجز، والإعادة تستكمل دون إنشاء هويات أو عضويات. التراجع إعادة تعيين
كلمات جديدة، وليس استعادة أسرار الإنتاج. الملف الخاص 0600 يحدث بعد كل نجاح.
الاختبار: preflight يمنع IDs أخرى والمدير، تحقق bcrypt لكل حساب، دخول ممثل
خليل مع الكلمة الجديدة والتحقق أن السياق المؤسسي محجوب حتى الاستبدال، وثبات
بصمة حساب المدير وعدد العضويات، مع بوابة حوكمة التطوير. لا تغيير واجهات أو عقود.

نتيجة التوحيد: نجح تحقق Auth والبصمة المؤقتة لكل الحسابات الخمسين، وبقي إلزام
الاستبدال قائمًا للخمسين. نجح دخول خليل بالكلمة الجديدة، والسياق المؤسسي محجوب
حتى استبدالها. ألغيت الجلسات السابقة وجلسة الاختبار بالعقد المدقق، وبقيت بصمة
المدير والعضويات دون تغيير. حُدث ملف الكلمات الخاص خارج Git، ولم يُكتب إلى الإنتاج.
