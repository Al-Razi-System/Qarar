# نشر البند وحده ومساحة قراءة أوضح

## خريطة الأثر قبل التنفيذ

الخلل المثبت: زر تنشيط النص ينشر المسودة كاملة، وتغيير حالة بند من مسودة ينشر
تعديلات البنود الأخرى. المستخدم يريد إجراءات البند داخل البند وبأثر منفصل.

الرحلة: إنشاء/حفظ مسودة بند ← تنشيط هذا البند وحده ← اختيار السند الجديد؛ النصوص
المحفوظة للموضوعات القديمة تظل مرتبطة بمفاتيحها. المدير يحتاج read وmanage فقط.
القارئ والمستخدم من مؤسسة أخرى لا يغيران الحالة.

المتأثر: RegulationLibrary، نافذة التأكيد، CSS Module، API اللوائح، أمر V2 وقراءة
التفاصيل، policies/policy_versions/policy_items/policy_attachments، التوريث والتدقيق
وإيصالات التكرار. مطابقة السند تستخدم النسخة النافذة وis_active؛ لا مهمة خلفية أو
إشعار جديد، ولا تغيير للاجتماعات أو بيانات الإنتاج أو صلاحيات المستخدمين.

التصميم الخلفي: إبقاء مسودة العمل، وإنشاء لقطة نافذة موروثة من النص النافذ الحالي
وليس مسودة العمل. يُنقل البند المحدد فقط عند تنشيطه. البنود غير المنشورة لا تدخل
اللقطة، وتعديلات البنود الأخرى لا تتغير فيها. ننقل حاويات البند الهيكلية فقط عند
الحاجة، ونحفظ المرفق والسند والمرجع. التعطيل ينسخ النص المنشور السابق للبند ولا
ينشر تعديلًا معلقًا حتى للبند نفسه. آخر بند يمكن تعطيله.

قبل النجاح: draft أو effective مكتبة؛ بعده: لقطة effective جديدة ومسودة عمل باقية.
الفشل يعيد الحالة واللقطة والتدقيق والإيصال ذريًا. UUID التاريخية لا تتغير، المرجع
المقروء يستمر عبر اللقطات. قفل اللائحة وبصمة مراجعة وإيصال تكرار يحميان التزامن.
السجلات السابقة لا تُحوّل جماعيًا؛ العقود القديمة محفوظة للتوافق، الأمر الفردي جديد.

الواجهة: عنوان البند وحالته وأزراره في شريط واحد، حذف داخل «المزيد»، لا زر نشر
جماعي ولا إعدادات إصدار في الرحلة الأساسية. للمحرر تظهر مسودة العمل وحالة النشر
الحقيقية لكل بند. للقارئ يظهر النص النافذ فقط. تحميل/فشل/نجاح في موضع الإجراء.

اختبار فاشل أولًا: بندان جديدان وتنشيط واحد؛ نشرهما ثم تعديل الاثنين ونشر أحدهما،
إثبات أن الآخر لم يتغير وأن مسودته محفوظة. تعطيل مع تعديل معلق، إعادة التفعيل،
المرفقات، رفض الصلاحية والمؤسسة الأخرى، تكرار وتعارض، حماية التاريخ. واجهة desktop
و390px مع لقطة بصرية، نوافذ وأخطاء، ثم اختبارات التوريث والمكتبة والعقود المجاورة.
ترحيل أمامي على التطوير فقط؛ lint/typecheck/development-governance ومطابقة الترحيلات.

## نتيجة التنفيذ والتحقق

- الترحيلان 20261008013000 و20261008014000 على قاعدة التطوير فقط؛ الثاني يحفظ
  حقل إمكانات النشر القديم بمعناه السابق بعد كشف اختبار التوافق غيابه.
- اختبار 71 بدأ فاشلًا قبل الأمر الجديد، وأصبح يمر بـ22 تحققًا، بما فيها عدم نشر
  مسودة أخرى، حفظ المصدر، آخر بند، رفض الحذف، إيصال التكرار والتعارض وحدود الصلاحية.
- اختبارات 13 و30 و47 و57 و69 و70 تمر دون تعديل التوقعات القديمة.
- رحلة متصفح فعلية على devqarar، بمؤسسة وهوية اختبار معزولتين: إنشاء/فشل وإعادة
  محاولة/إضافة/تعديل/حذف/تنشيط بند مع إبقاء بند آخر مسودة/تعطيل وإعادة تفعيل/أرشفة
  واستعادة/طلبات متزامنة، مع فحص عرض مكتبي و390px وعدم أخطاء JavaScript.
- لقطات القراءة والنافذة فُحصت بصريًا. لم تتغير بيانات أو كلمات مرور المستخدمين
  الحاليين، ولم يتم نشر أو تطبيق ترحيل على الإنتاج.
