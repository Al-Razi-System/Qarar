# إصلاح مدخل إنشاء الموضوع

العيب المثبت من الصورة والكود: /admin/topics يعرض زر إنشاء موضوع يفتح
TopicRegulationCreator القديم، إضافة لرابط آخر إلى /admin/topics/new.
الاختبار السابق غطى الرابط المباشر فقط؛ لم يغط زر المستخدم الرئيسي.

القاعدة: كل إنشاء جديد من قائمة الموضوعات يفتح الرحلة المصنفة نفسها:
مجلس مخول ثم تصنيف منشور متاح له، تعليمات ومتطلبات ثم بيانات وتقديم.
لا فئة يدوية ولا اختيار لائحة أو مسار أو استثناء عند الإنشاء. العقود
التاريخية وقراءة الموضوعات القديمة باقية؛ لا حذف سجلات ولا تعديل مساراتها.

السابق: قائمة موضوعاتي/المراجعة وصلاحية topics.create. المعدل: مدخل إنشاء
واحد، وخيارات مجالس فقط. التالي: التحضير والإنشاء المصنف، ثم التفاصيل
والمرفقات والمراجعة بالعقود القائمة. لا تغيير لحالة new أو التدقيق.

العقد القديم get_topic_form_options يعيد وحدات تنظيمية أيضًا للمسؤول.
نضيف get_typed_topic_form_options_v2: قراءة مجالس نشطة من أنواع مجالس نشطة
في مؤسسة المستخدم، وبصلاحية topics.create في المجلس نفسه. لا قائمة فئات
ولا حقل مرجع ولا فئة/مسار/لائحة يقبلها API الجديد. الترحيل أمامي إضافة فقط؛
لا تغيير get_topic_form_options لأن المنشئ القديم والتوافق قد يستهلكانه.

الواجهات: TopicsPage وTopicsWorkspace وTypedTopicCreator وAPI typed-topics.
مستهلكون: اختبار الدخان وE2E الإنشاء القديم يجب استبدال توقعاته بالرحلة
الجديدة، واختبار متصفح التصنيف يبدأ الآن من زر القائمة لا الرابط المباشر.
مالك القراءة topics_executor وapi_executor، authenticated فقط؛ لا service-role
في قراءة واجهة المستخدم. source tables core.units/types وIAM سياقي.

اختبارات قبل التنفيذ: زر القائمة رابط للمنشئ الجديد وعدم وجود modal قديم،
عدم ظهور الزر لغير المخول، خيارات القراءة لا تتضمن وحدة أو مؤسسة أخرى أو
مجلسًا معطلًا أو خارج النطاق؛ ثم التصنيف والتعليمات وتقديم مرة واحدة.
الاختبارات السابقة للمرفقات والمراجعة واللقطة التاريخية تبقى. 1440/390،
lint/typecheck/build والبوابة. لا نشر إنتاجي؛ الإصلاح الأمامي يعيد مدخل الرابط
دون الرجوع ببيانات أو تعديل ترحيل مطبق.

## التحقق

- اختبار المدخل فشل أولًا لأن الزر كان يفتح المنشئ القديم، ثم نجح بعد الربط.
- سياق مدير النظام لا يسرد بالضرورة topics.create دون عضويات؛ المدخل يحترم
  is_system_admin أيضًا، مع استمرار تحقق الصلاحية السياقية داخل RPC.
- 14 اختبارًا مركزًا للمدخل وصفحة القائمة والتحضير وAPI والمرفقات نجحت.
- اختبارات قاعدة البيانات 79 و83 و87 نجحت: 78 حالة، مع المؤسسة والنطاق
  والتعطيل وإعادة المحاولة والمرفقات والمرحلة التالية.
- اختبار المتصفح المعزول بدأ من /admin/topics وزر إنشاء موضوع، ثم قدم
  موضوعًا حقيقيًا ورفع مرفقين وفتح التفاصيل، واختبر فقد الرد وإعادة الطلب
  بالمفتاح نفسه دون تكرار، والعرض 1440 و390 دون تجاوز أفقي.
- حُدّث اختبار Playwright القديم إلى الرحلة الجديدة؛ لم يُشغّل ملفه منفردًا
  لأن إعداداته تستخدم قاعدة محلية أخرى. التحقق الفعلي أعلاه على DEV المعزول.
- lint بلا أخطاء مع ستة تحذيرات سابقة؛ typecheck والبناء و79 اختبار عقود
  وبوابة التطوير نجحت. سجل DEV يطابق 268 ترحيلًا. لا نشر إنتاجي.
