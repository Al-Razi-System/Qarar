# عرض شجرة الوحدات ومجالسها

## الحاجة والثابت
الشجرة القديمة تعرض تبعية المجلس الأب التاريخية. المطلوب عرض شجرة الوحدات التنظيمية مصدرًا واحدًا، ووضع كل مجلس داخل وحدته دون استنتاج أب للمجلس أو تغيير مسار الموضوع. مهلة الموعد للتنبيه ورصد التجاوزات فقط؛ لا تغيير لجدولة الاجتماعات أو توليد الدورات التالية.

## الرحلة والأثر قبل التنفيذ
- السابق: إنشاء الوحدات وتبعيتها وربط المجلس بـscope_unit_id. المرحلة المعدلة قراءة وعرض فقط. التالي اختيار مجلس وإدارة الأعضاء والقيادة والجاهزية بالعقود السابقة.
- عقد قراءة جديد api_v2.admin_get_council_organizational_tree_v2، ينفذ في core على governance_units وgovernance_unit_types. يقرأ المنظمة الحالية فقط بعد governance.units.read؛ لا مهام أو مشغلات أو كتابة أو تعديلات تقارير أو حالات أو معرفات.
- الواجهة: صفحة المجالس Server Component ثم مساحة المجالس ومكوّن شجرة تفاعلي مستقل. Route Handler يضيف العقد إلى قائمة السماح ويوجهه إلى V2. عقود V1 والتبعية التاريخية محفوظة دون تعديل.
- الوحدات المؤرشفة المرتبطة بمجالس تظهر للحفاظ على موقعها التاريخي. تخفى الفروع بلا مجالس، وتبقى الأسلاف الضرورية فقط. عدة مجالس داخل وحدة تظهر كعناصر متوازية. المجالس بلا وحدة ضمن نطاق المؤسسة؛ ارتباط غير متاح يظهر صراحة وليس تحت أب مفترض. لا حد أول 100 مجلس في القراءة الجديدة.
- نجاح القراءة لا يغير قاعدة البيانات. عند فشل التحديث تحفظ الشجرة السابقة ويظهر الخطأ وإعادة المحاولة في مساحة الهيكل. البحث محلي على اللقطة الكاملة ويحتفظ بالأسلاف، والطي لا يخفي نتيجة البحث. منع سباق استجابات التحديث.
- التصميم: بطاقات وحدات، خطوط وصل RTL، تمييز المجلس المختار، طي وفرد، حالات واضحة، اختيار مجلس يفتح التفاصيل الموجودة؛ قوائم وأزرار أصلية قابلة للوصول بلوحة المفاتيح، تدرج محدود على الهاتف دون تمرير أفقي للصفحة.

## الاختبارات والإصدار
اختبارات فاشلة أولًا: تفرع رئاسة/كلية/قسم، مجلسان للوحدة، وحدة فارغة، مجلس مؤسسي، حفظ الأسلاف في البحث، الطي والاختيار، بيانات دورية أو يتيمة دون فقد أو تعطل. عقود قاعدة البيانات للصلاحية المسموحة والمرفوضة وحدود المنظمة والأرشفة والعدد الكامل وعدم تغير القراءة التاريخية. اختبار المتصفح بمؤسسة معزولة على الكمبيوتر و390px وفتح تفاصيل المجلس وفشل التحديث وإعادة المحاولة.

ترحيل جديد للقراءة وسجل العقود فقط، على التطوير المعزول. لا تعديل مستخدمين أو بيانات قائمة أو إنتاج. التراجع التشغيلي يعيد الواجهة إلى القراءة القديمة دون الحاجة إلى حذف العقد الجديد. typecheck وlint والاختبارات المركزة والعقود والحوكمة ودفتر الترحيلات بوابات التسليم.

## عقد القراءة

## مراجعة العرض بناءً على قبول المستخدم

المطلوب المحدث: إخفاء الوحدة إن لم يوجد مجلس فيها أو في أي فرع تابع، حتى عند البحث باسمها. إبقاء الأسلاف اللازمة للوصول إلى المجالس فقط؛ لا حذف أو تغيير لسجلات الوحدات. تعديل نموذج العرض ومكوّن الشجرة واختبارات البحث والطي والمتصفح؛ عقد القراءة والصلاحيات والجدولة لا تتغير. استبدال البطاقات المتداخلة بصفوف شجرية مدمجة وخطوط وصل وCSS Module محدد النطاق لضمان تنسيق المكوّن مستقلًا عن توليد أصناف Tailwind الجديدة. الفشل والتحديث والتفاصيل تبقى كما هي. اختبار الوحدات الفارغة يصبح اختبار عدم ظهورها، مع حفظ الأسلاف الذين لا يملكون مجلسًا مباشرًا.

الطلب عبر `POST /api/admin/councils` باسم `admin_get_council_organizational_tree_v2` دون معاملات؛ الجلسة وCSRF وقائمة السماح مطبقة كما هي. الناتج لقطة `{units:[], councils:[]}`؛ كل وحدة تحمل `id,parent_unit_id,name_ar,code,status,type_name_ar` وكل مجلس ملخصه السابق مع `scope_unit_id`. القيم UUID ثابتة؛ الواجهة لا تولد هوية أو تصنيفًا أو تبعية جديدة. الخطأ يحفظ سببه في سجل Route Handler مع رمز تتبع ويعرض النص العربي الآمن من غلاف الاستجابة.

## التحقق المنفذ

- الاختبارات المركزة: 25 اختبارًا ناجحًا لحماية العرض الجديد وRoute Handler ونماذج المجلس والقيادة؛ أضيف اختبار إخفاء الوحدة الفارغة حتى عند البحث باسمها بعد رفض التصميم الأول.
- قاعدة البيانات: 125 تحققًا ضمن تسع حزم، تشمل CRUD والعضويات والجاهزية ودورة الاجتماع والعقود السابقة وقراءة الشجرة. اختبار القراءة أثبت إرجاع 114 مجلسًا دون قطع أول 100، حفظ الوحدات المؤرشفة، منع غير المخول وعزل المنظمة.
- بيئة التطوير: دفتر الترحيلات مطابق لـ224 ملفًا؛ لا ترحيل أو تعديل إنتاجي.
- إجراء المتصفح القابل للإعادة: `node scripts/test-organizational-council-tree-dev-browser.mjs`؛ مؤسسة وحساب مؤقت مستقلان مع MFA حقيقي، ثم تعطيل حساب الاختبار. يغطي رئاسة/كلية/قسم، مجلسين في الوحدة، مجلسًا مؤسسيًا، الاختيار وتفاصيل العضويات، البحث والطي، فشل التحديث وتعافيه، وعرض 390px دون تمرير أفقي.
- رحلة المرحلة السابقة والتالية: `node scripts/test-organizational-units-dev-browser.mjs` نجحت؛ إضافة النوع والوحدة، إنشاء المجلس وخطة أول اجتماع، تعديل الوحدة وتعطيلها وإعادتها وأرشفتها، إنشاء الاجتماع وجدولته وتجهيز الدعوات، وأخطاء النافذة على الهاتف.
- بعد إعادة التصميم: اختبار المتصفح للشجرة ناجح على الكمبيوتر و390px، مع مراجعة اللقطات بصريًا؛ typecheck وeslint وdevelopment-governance ناجحة. لا تغير في قاعدة البيانات ضمن مراجعة التصميم.
