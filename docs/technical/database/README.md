# مراجع قاعدة البيانات

يحتوي هذا المجلد على لقطة مولدة آلياً لمخطط قاعدة بيانات قرار، وتستخدم مرجعاً إلزامياً قبل كتابة استعلامات SQL أو عقود API أو ترحيلات جديدة.

لتحديث المرجع بعد تشغيل أي Migration:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\export-database-schema-reference.ps1
```

الملفات الناتجة:

- `Qarar_Database_Schema_Reference_Arabic.md`: مرجع مقروء يشمل الحقول والقيود والعلاقات والفهارس والدوال.
- `qarar-schema-reference.json`: مرجع منظم قابل للبحث والمعالجة الآلية.

قاعدة العمل: لا يُفترض اسم مخطط أو جدول أو حقل من الذاكرة. يجب التحقق أولاً من هذا المرجع، وعند التعارض تكون Migration المطبقة وقاعدة البيانات الفعلية هما المصدر النهائي للحقيقة.
