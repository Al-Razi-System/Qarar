# خريطة توافق حوكمة V1 وV2

## نتيجة الجرد

الحدود القديمة مستخدمة فعلياً في 14 ملفاً من مصدر لوحة التحكم، واختباري E2E، و14 ملف اختبار قاعدة/تكامل، و6 وثائق API. لذلك يمنع حذفها أو تغيير شكل استجابتها أثناء بناء V2.

## قرارات الحدود

| الحد القديم | القرار | البديل/التكامل | شرط القطع |
|---|---|---|---|
| `topic_categories` | يبقى | يفصل لاحقاً إلى تصنيف ونوع موضوع | نجاح محول الخيارات واختبار أن التصنيف لا يختار المسار |
| `policy_items.topic_category_id` | يبقى مؤقتاً | سند مستقل مرتبط بنوع الموضوع | خريطة سند كاملة بلا تكرار أو فقد |
| `policy_items.workflow_template_version_id` | قراءة مزدوجة لاحقاً | `topic_type_workflow_bindings_v2` | تطابق معاينة المسار وأول خطوة والنتائج |
| محرك `workflow_template_versions` | يعاد استخدامه | V2 يربط النوع بالإصدار الحالي | لا استبدال للمحرك في هذه المرحلة |
| `topic_prior_route_requests` | يبقى حتى بناء V2 | يتغير المراجع إلى رئيس مجلس الوجهة | اختبارات السماح والمنع والتعارض والمعاملة الذرية |
| `meeting_series` | يبقى | يفصل rule/occurrence/meeting | محرك كسول لا يحول الموعد إلى اجتماع منعقد |
| مكلف واحد في `action_items` | يبقى | تكليف متعدد الأهداف ومتحقق | استمرار المهام المفتوحة واختبار القبول والأدلة |

## الرحلات التي يجب أن تبقى سليمة

1. إنشاء اللائحة وإصدار جديد ووراثة البنود والمراجع والمرفقات.
2. إنشاء موضوع بالطريقة الحالية، ومعاينة مساره، واستكمال المسار السابق.
3. استمرار أي موضوع جارٍ على لقطة مساره القديمة دون تغيير.
4. إنشاء اجتماع وسلسلة حالية وعرضها وتعديل تكرارها.
5. الاجتماع الحي والتصويت والقرار والمحضر والتوقيعات.
6. استمرار التكليفات القديمة والمستخدم البديل عند إيقاف حساب.

## أسلوب الانتقال

1. **إضافة:** V2 معزول ولا يغير V1.
2. **محول:** طبقة داخلية تقرأ V2 وتنتج عقد القراءة المتوقع دون تغيير الواجهة.
3. **ظل:** نفس الطلب يحسب نتيجة V1 وV2، لكن V1 وحده ينفذ؛ الاختلاف يسجل مع `trace_id`.
4. **اختيار محدود:** مؤسسة/نوع موضوع تجريبي يستخدم V2 خلف feature flag.
5. **قطع:** بعد نجاح البوابات، تصبح V2 المصدر، ويبقى V1 للقراءة والرجوع مؤقتاً.
6. **إيقاف:** لا حذف قبل جرد صفري للمستهلكين وقرار ترحيل مستقل.

## ما هو محظور الآن

- تعديل توقيع أو استجابة RPC قديمة.
- ملء حقول V2 من V1 تلقائياً دون خريطة معتمدة.
- تفعيل نوع موضوع V2 أو ربط واجهة إنشاء الموضوع به.
- تغيير مسار موضوع قائم بسبب تفعيل إصدار جديد.
- حذف حقول `policy_items` أو `action_items` أو جداول السلاسل.
