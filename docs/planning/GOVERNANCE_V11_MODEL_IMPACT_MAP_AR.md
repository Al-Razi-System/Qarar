# خريطة أثر تأسيس نموذج حوكمة الإصدار الحادي عشر

## تعريف التغيير

- **الحاجة:** اعتماد الأجزاء الصحيحة من ملف «مصحح الربط» كأساس لنموذج بيانات وعقود تمنع خلط السند القانوني بنوع الموضوع أو مساره.
- **القاعدة التجارية:** المسار يخص نوع الموضوع ونسخته، بينما البند/السند يثبت مصدر الاختصاص ويمكن أن يرتبط بمرحلة أو أكثر؛ قواعد الاجتماع مستقلة عن مسار الموضوع.
- **السلوك الحالي المثبت:** `policy_items` تربط البند مباشرة بتصنيف ومسار، وبعض بيانات المصدر تجمع عدة مجالس في حقل واحد، كما أن ملف Excel يجمع مسارات الموضوع وسياسات الاجتماع في ورقة واحدة.
- **السلوك المتوقع:** عقد إدخال يفصل `authority_records`, `topic_types`, `topic_workflows`, `meeting_policies`, و`schedule_policies`، ويرفض التفعيل عند نقص الربط أو وجود تعارض.
- **خارج النطاق في هذه الدفعة:** ترحيل قاعدة البيانات الإنتاجية، استيراد البيانات، تفعيل المسارات، وتعديل واجهات المستخدم.

## خريطة الرحلة

- **المرحلة السابقة:** تدقيق المصدر واعتماد السندات.
- **المرحلة المعدلة:** تحويل السجلات المقبولة إلى عقد تأسيسي م版本 وقابل للتحقق.
- **المرحلة التالية:** إنشاء ترحيل أمامي وعقود API ثم واجهات الإدارة والاستيراد المرحلي.
- **الحالة قبل العملية:** سجل مصدر `candidate` أو `blocked`.
- **شروط السماح:** معرف فريد، سند ومادة وبند ونص، نوع صلاحية مضبوط، وعدم وجود تكرار غير محسوم.
- **الحالة بعد النجاح:** `accepted_as_authority_source` فقط؛ لا يعني ذلك تفعيل موضوع أو مسار إنتاجي.
- **الحالة بعد الفشل:** `blocked` مع رمز سبب ومكان السجل، دون استيراد جزئي صامت.

## خريطة التأثير

- **الواجهات:** مستقبلًا شاشة أنواع الموضوعات، شاشة ربط المسار، شاشة مصادر السند، وسياسة الاجتماع.
- **API/RPC:** مستقبلًا عقود قائمة/إنشاء/إصدار/تفعيل أنواع الموضوعات وروابط الأسانيد والمسارات.
- **الجداول المتوقعة:** أنواع الموضوعات، روابط النوع بالسند، روابط النوع بإصدار المسار، سند المرحلة، سياسة الجدولة، وسياسة الاجتماع.
- **المهام المجدولة:** مولد استحقاقات الموضوعات ومولد اجتماعات المجالس، كلٌ بعقد مستقل.
- **التقارير والتدقيق:** مصدر الملف وبصمته، نتيجة كل سجل، سبب الحجب، ونسخة العقد.
- **الأدوار:** محرر الحوكمة ينشئ المسودة؛ المراجع القانوني يعتمد السند؛ مسؤول الحوكمة يعتمد الربط؛ النظام ينفذ التوليد فقط بعد التفعيل.
- **المستهلكون:** محرك مطابقة الموضوع، معاينة المسار، إنشاء الموضوع، استكمال المسار السابق، جدول الأعمال، المحضر، ومتابعة القرار.
- **البيانات القديمة:** لا تُحذف ولا تُعاد كتابتها في هذه الدفعة؛ يلزم لاحقًا جدول ربط للمراجع القديمة.

## خطة الاختبار

- رفض سجل بلا سند أو مادة أو بند.
- رفض `Topic_ID` أو `Authority_ID` مكرر.
- رفض مسار موضوع بلا `topic_type_code` موحد.
- رفض مرحلة بلا نتيجة قبول ورفض/إغلاق معرفة.
- منع تصنيف سياسة اجتماع كمسار موضوع.
- التحقق من بصمة ملف المصدر وقائمة المقبول والمحجوب.
- اختبار ترقية لاحقة على قاعدة قديمة قبل أي استيراد.

## خطة الإصدار

- هذه الدفعة تنتج عقودًا وقرار اعتماد فقط، بلا تغيير إنتاجي.
- الترحيل التالي سيكون أماميًا ويبدأ بجداول مسودة غير مستخدمة من الرحلات الحالية.
- لا يتم الاستيراد أو التفعيل قبل نجاح اختبار التكامل وقرار اعتماد البيانات.
