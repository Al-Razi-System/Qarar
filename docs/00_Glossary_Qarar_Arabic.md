# قاموس المصطلحات المرجعي - Qarar

**اسم الوثيقة:** القاموس المرجعي للمصطلحات  
**اسم المنتج:** Qarar  
**اللغة الأساسية:** العربية  
**الحالة:** مسودة للمراجعة التأسيسية  
**الغرض:** توحيد اللغة المفاهيمية والوظيفية والتقنية عبر جميع وثائق المشروع  

---

## 1. الدور المرجعي

تمثل هذه الوثيقة المرجع الرسمي للمصطلحات المستخدمة في مشروع `Qarar`. ويجب الرجوع إليها عند أي اختلاف في الصياغة بين وثائق الرؤية، والتحليل، ونموذج المجال، والمتطلبات، والأمن، والصلاحيات، والواجهات البرمجية، وتجربة المستخدم، وخارطة التنفيذ.

يستخدم هذا القاموس من أجل:

- تثبيت الاسم العربي المعتمد لكل مفهوم.
- تثبيت المقابل الإنجليزي عند الحاجة.
- تعريف المفهوم داخل المشروع لا في الاستخدام العام فقط.
- توضيح المصطلحات التي لا يجوز استخدامها بالتبادل.
- تثبيت الحالات التشغيلية المعتمدة للكيانات الأساسية.

---

## 2. قواعد الاستخدام

- تستخدم العربية كلغة شرح وتعريف أساسية.
- يستخدم الاسم الإنجليزي حين يكون جزءاً من لغة التصميم أو البيانات أو الـ API.
- لا يجوز استخدام أكثر من مصطلح لمفهوم واحد دون تمييز صريح.
- يجب التفريق دائماً بين الكيان، والحالة، والإجراء، والدور، والقاعدة.
- عند اعتماد مصطلح جديد لاحقاً، يجب إضافته هنا قبل تعميمه على بقية الوثائق.

## 3. مصطلحات المجال الأساسية

### 3.1 Qarar

- **الاسم العربي:** قرار
- **المقابل الإنجليزي:** `Qarar`
- **التعريف:** اسم المنصة المؤسسية التي تدير الحوكمة والاجتماعات والقرارات والتنفيذ والمتابعة والامتثال ضمن نموذج SaaS.
- **لا يستخدم بدلاً عنه:** نظام اجتماعات فقط، أو نظام محاضر فقط.

### 3.2 Organization

- **الاسم العربي:** المؤسسة
- **المقابل الإنجليزي:** `Organization`
- **التعريف:** الكيان الأعلى الذي يملك بيانات المنصة والوحدات الحوكمية والمستخدمين والسياسات داخل نطاقه.

### 3.3 Governance Unit

- **الاسم العربي:** الوحدة الحوكمية
- **المقابل الإنجليزي:** `Governance Unit`
- **التعريف:** أي كيان مؤسسي يشارك في مناقشة موضوع أو مراجعته أو التوصية به أو اعتماده أو متابعته.
- **لا يستخدم بدلاً عنه:** مجلس فقط، أو لجنة فقط، أو إدارة فقط.

### 3.4 Governance Unit Type

- **الاسم العربي:** نوع الوحدة الحوكمية
- **المقابل الإنجليزي:** `Governance Unit Type`
- **التعريف:** التصنيف البنيوي للوحدة الحوكمية مثل مجلس أو لجنة أو إدارة أو هيئة.

### 3.5 Membership

- **الاسم العربي:** العضوية
- **المقابل الإنجليزي:** `Membership`
- **التعريف:** العلاقة الرسمية بين المستخدم والوحدة الحوكمية والتي تحدد موقعه ودوره ضمنها.

### 3.6 User

- **الاسم العربي:** المستخدم
- **المقابل الإنجليزي:** `User`
- **التعريف:** الشخص أو الحساب المخول باستخدام المنصة وفق صلاحيات محددة.

## 4. مصطلحات السياسات والمسارات

### 4.1 Policy / Regulation

- **الاسم العربي:** اللائحة أو السياسة
- **المقابل الإنجليزي:** `Policy / Regulation`
- **التعريف:** الإطار التنظيمي الذي يحكم بعض الموضوعات أو الاعتمادات أو المسارات أو قواعد الامتثال.
- **لا يستخدم بدلاً عنه:** المسار، أو القرار، أو الحالة التشغيلية.

### 4.2 Policy Item

- **الاسم العربي:** بند اللائحة أو بند السياسة
- **المقابل الإنجليزي:** `Policy Item`
- **التعريف:** بند تفصيلي داخل لائحة أو سياسة يمكن ربطه بموضوع أو مسار أو قاعدة اعتماد.

### 4.3 Workflow

- **الاسم العربي:** المسار
- **المقابل الإنجليزي:** `Workflow`
- **التعريف:** التسلسل الحوكمي الذي ينتقل عبره الموضوع بين الجهات أو الخطوات أو حالات المعالجة.
- **لا يستخدم بدلاً عنه:** الاجتماع، أو القرار، أو الإجراء المفرد.

### 4.4 Workflow Step

- **الاسم العربي:** خطوة المسار
- **المقابل الإنجليزي:** `Workflow Step`
- **التعريف:** مرحلة واحدة داخل المسار تحدد الجهة المسؤولة ونوع العمل المتوقع في تلك المرحلة.

### 4.5 Workflow Transition

- **الاسم العربي:** انتقال المسار
- **المقابل الإنجليزي:** `Workflow Transition`
- **التعريف:** الانتقال المنطقي من خطوة إلى أخرى داخل المسار وفق قاعدة أو نتيجة معالجة.

### 4.6 Exception Workflow

- **الاسم العربي:** المسار الاستثنائي
- **المقابل الإنجليزي:** `Exception Workflow`
- **التعريف:** مسار يستخدم عندما لا ينطبق المسار اللائحي الأساسي أو عند وجود حاجة تشغيلية خاصة.

### 5.8 Vote

- **المقابل الإنجليزي:** `Vote`
- **التعريف:** التعبير الرسمي عن رأي العضو تجاه موضوع أو قرار وفق آلية معتمدة.
- **لا يخلط مع:** الاعتماد أو المصادقة الرسمية.

## 6. مصطلحات القرار والتنفيذ

### 6.1 Decision

- **الاسم العربي:** القرار
- **المقابل الإنجليزي:** `Decision`
- **التعريف:** النتيجة الرسمية الصادرة عن معالجة موضوع داخل سياق حوكمي معتمد.
- **لا يستخدم بدلاً عنه:** `Decision Record`.

### 6.2 Decision Type

- **الاسم العربي:** نوع القرار
- **المقابل الإنجليزي:** `Decision Type`
- **التعريف:** التصنيف الذي يحدد طبيعة القرار مثل تنفيذي أو توصية أو إحالة أو اعتماد أو رفض.

### 6.3 Decision Note

- **الاسم العربي:** ملاحظة القرار
- **المقابل الإنجليزي:** `Decision Note`
- **التعريف:** شرح أو تعليق أو توثيق إضافي مرتبط بالقرار.

### 6.4 Action Item

- **الاسم العربي:** التكليف التنفيذي
- **المقابل الإنجليزي:** `Action Item`
- **التعريف:** الأثر التنفيذي الناتج عن قرار يتطلب عملاً قابلاً للتنفيذ والقياس والمتابعة.

### 6.5 Follow-Up

- **الاسم العربي:** المتابعة
- **المقابل الإنجليزي:** `Follow-Up`
- **التعريف:** النشاط التشغيلي الذي يراقب تقدم التنفيذ والتأخر والشواهد وحالة الإنجاز.

### 6.6 Escalation

- **الاسم العربي:** التصعيد
- **المقابل الإنجليزي:** `Escalation`
- **التعريف:** رفع الحالة أو القرار أو التكليف إلى جهة أعلى عند تحقق شرط زمني أو تشغيلي أو حوكمي.

### 6.7 Evidence

- **الاسم العربي:** الشواهد والأدلة
- **المقابل الإنجليزي:** `Evidence`
- **التعريف:** المستندات أو المرفقات أو الروابط أو البيانات التي تثبت التقدم أو الإنجاز أو الالتزام.

### 6.8 Closure

- **الاسم العربي:** الإغلاق
- **المقابل الإنجليزي:** `Closure`
- **التعريف:** الإنهاء الرسمي لكيان أو دورة تشغيلية بعد استكمال شروطه المعتمدة.
- **لا يخلط مع:** الإلغاء أو الحذف.

## 13. الفروق الواجب حمايتها

- `Approval` مفهوم حوكمي، أما `Authentication` فمفهوم أمني.
- `Decision` هو النتيجة الرسمية، و`Action Item` هو أثره التنفيذي إن وجد.
- `Topic` هو الكيان الأساسي، و`Agenda Item` هو إدراجه داخل اجتماع.
- `Meeting Minutes` هو المحضر النهائي، و`Minutes Draft` هي النسخة الأولية.
- `Closure` يعني إنهاءً بعد استكمال الشروط، و`إلغاء` يعني إيقافاً قبل اكتمال الغرض.
- `Notification` ليس مرادفاً لـ `Escalation`؛ التصعيد حالة أعلى من الإشعار العادي.
- `Vote` لا يساوي `Approval`؛ التصويت تعبير رأي، والاعتماد منح شرعية أو قبول رسمي.
