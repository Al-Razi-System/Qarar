# مجالس تقديم الموضوع

`api_v2.get_typed_topic_form_options_v2()` عقد قراءة للمستخدم المسجل النشط.
يعيد `{governance_units: [{id, name_ar}]}` للمجالس النشطة ذات النوع الفعال
ضمن المؤسسة وصلاحية `topics.create` السياقية للمستخدم. لا يعيد وحدات تنظيمية
أو فئات يختارها مقدم الموضوع.

بعد اختيار المجلس تستخدم الواجهة `list_effective_topic_types_v2` ثم
`prepare_typed_topic_v2`. يبقى إنشاء الموضوع عبر `create_topic_from_type_v2`
مع تحقق مستقل من الصلاحية والنطاق واشتقاق السياسة والمسار والسند من التصنيف.
لا يتغير عقد `get_topic_form_options` القديم ولا سجلات الموضوعات السابقة.
